# Automation Testing Demo

This intention of this project is to demonstrate facility with Automation Testing and CI/CD Pipeline technologies, covering aspects of code quality, specifically in python, such as linting and formatting using ruff, type checking with pyright, unit testing using pytest and coverage, Automation testing using Playwright.

Metrics for the test coverage are currently published via an integration to https://codecov.io:
